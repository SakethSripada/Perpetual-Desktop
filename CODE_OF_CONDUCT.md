# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, and harassment-free community. Be constructive, assume good intent, respect differing viewpoints, and focus feedback on the work rather than the person.

Unacceptable behavior includes harassment, discrimination, threats, deliberate intimidation, publishing another person's private information, and sustained disruption of project spaces.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub profile. Reports will be reviewed promptly and handled as confidentially as practical. Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior violates this standard.

This code applies in project spaces and when someone is representing the project in public spaces.
