# Security Policy

## Supported versions

Security fixes are released in the latest version of Perpetual. Please update before reporting an issue.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository. If that option is unavailable, contact the repository owner privately through their GitHub profile.

Include the affected component, reproduction steps, impact, and any suggested mitigation. Do not include real provider credentials, private prompts, or third-party repository contents.

Please allow a reasonable period for investigation and remediation before public disclosure.
